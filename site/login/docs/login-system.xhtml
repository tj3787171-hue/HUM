HUM.org SQL login system

This desk stores local lab accounts in SQLite. PHP and Python share sql/schema.sql and the same PBKDF2 password string.

Tables

  • users — username, email, password hash, display name
  • sessions — random cookie token and expiry
  • login_attempts — success or failure for throttle
  • csrf_tokens — one-time form tokens

Run without PHP

python3 site/login/tools/init_auth_db.py init
python3 site/login/tools/init_auth_db.py seed --password 'LabOnly1234'
python3 site/login/tools/login_server.py --host 127.0.0.1 --port 8088

Security rules

  • Never store a raw password.
  • Always bind user input with prepared statements.
  • Keep the SQLite file out of the web root when you can; var/ is blocked by .htaccess.
  • This is a local lab login, not an internet identity provider.
